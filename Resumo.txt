- Escrevendo no console

    O comando console.log() é uma função do JavaScript usada para exibir informações no console do navegador, sendo muito útil para depuração e acompanhamento da execução do código.

    Exemplo:

    console.log("Olá mundo");

    Para contatenar informações utilizamos a virgula "," ou o simbolo de soma "+".

    A "," aplica um espaço entre as informações ja o "+" não aplica, sendo necessario aplicar um espaço manualmente entre as informações.

    Exemplo:

    console.log("Olá", "mundo");

    console.log("Olá" + " " + "mundo");

    Utilizada para criar campos de texto chamdos "strings", por padrão é utilizada a aspas duplas cercando o texto conforme exemplo abaixo:

    O ponto e vírgula indica o fim de uma instrução, exmeplo:

- Palavras reservadas

    São palavras que pertencem à linguagem, elas possuem significado próprio e não podem ser usadas como identificadores de nenhum tipo, por exemplo as palavras abaixo:

    if
    new
    let

- Variaveis e constantes

    Uma variável é um espaço na memória utilizado para armazenar um valor.

    Declaração

        let - Forma moderna e recomendada quando o valor pode mudar, pode ser declarada vazia.
        const - Usada quando o valor não pode mudar (tipos comuns), obrigatoriamente tem de ser atribuido um valor ao ser declarada

    Convenção de nomes

        Não pode começar com número
        Não pode conter espaços
        Não pode usar palavras reservadas
        Pode usar letras, números, _ e $
        Usar padrão "camelCase", primeira palavra minúscula, próximas com inicial maiúscula.
        Constantes devem ter todas a letras em maiúsculo quando o valor é realmente fixo e imutável, algo que representa uma constante "global" ou  de configuração porem pode ser escita como variavel comum em casos comuns

    Observações importantes:

        const é a forma recomendada por padrão para declarar quaisquer tipo de variáveis atualmente
        const não torna o valor imutável para objetos / arrays, apenas impede a reatribuição da variável

    Exemplos:

        let idade = 20;
        const nome = "Fernando";
        const PI = 3.1415;

- Tipagem dinamica

    JavaScript é uma linguagem de tipagem dinâmica, ou seja:

    Você não define o tipo da variável
    O tipo é definido automaticamente pelo valor atribuído
    Uma variável pode mudar de tipo durante a execução

- Tipos de valores

    Os valores são divididos em duas grandes categorias: tipos primitivos e objetos.

    Tipos primitivos são valores simples, guardando apenas uma informação, por exemplo:

        const nome = "Maria";
        const idade = 25;

    Objetos armazenam coleções de dados e podem conter propriedades e métodos, guardando diversas informações, por exemplo:

        const pessoa = {
            nome: "Maria",
            idade: 25,
            falar() {
                console.log("Olá!");
            }
        };

- Tipos de dados

    number - Representa números inteiros e decimais
    string - Texto entre aspas simples, duplas ou crase
    boolean - Valores lógicos
    undefined - Variável declarada, mas sem valor atribuído
    null - Representa ausência intencional de valor
    symbol - Usado para criar identificadores únicos (mais avançado)
    bigint - Números inteiros muito grandes (com a letra "n" no final do numero)
    object - Usado para agrupar dados e funcionalidades em uma única estrutura, ele representa coleções de pares chave > valor

- Operadores

    Aritméticos

        Usados para realizar cálculos matemáticos:

        +  adição
        -  subtração
        *  multiplicação
        /  divisão
        %  resto da divisão (módulo)
        ** exponenciação

    Atribuição

        Usados para atribuir valores a variáveis:

        =   atribuição simples
        +=  soma e atribui
        -=  subtrai e atribui
        *=  multiplica e atribui
        /=  divide e atribui
        %=  módulo e atribui
        **= exponencia e atribui

    Incrementais / Decrementais

        Servem para aumentar ou diminuir valores em 1:

        ++ incremento
        -- decremento

        Temos pré-incremento / pré-decremento:

        let i = 5;
        ++i; // i = 6

        Temos pós-incremento / pós-decremento:

        let j = 5;
        j++; // j = 6 (mas retorna 5 antes de incrementar)

        Diferença importante:

        pré: altera antes de usar
        pós: usa o valor e depois altera

    Comparadores

        Usados para comparar valores. Sempre retornam true ou false.

        ==  igual (com conversão de tipo)
        === igual estrito (sem conversão)
        !=  diferente
        !== diferente estrito
        >   maior
        <   menor
        >=  maior ou igual
        <=  menor ou igual

- Ordem dos Operadores

    A ordem define quais operações são executadas primeiro.

    Ordem simplificada (do maior para o menor):

    ()             parênteses
    **             exponenciação
    ++ --          incremento / decremento
    * / %          multiplicação, divisão, módulo
    + -            adição e subtração  
    < <= > >=      comparações
    == != === !==  igualdade
    && AND         lógico
    || OR          lógico
    = += -= *= ... atribuição

- Template literals

    Template literals são uma forma mais moderna e poderosa de trabalhar com strings no JavaScript. Eles foram introduzidos no ES6 e usam crases (`) em vez de aspas simples ou duplas.

    Principais características

    Interpolação de variáveis: Com template literals, você pode inserir variáveis e expressões diretamente dentro da string usando ${ }.

    Exemplo:

    const nome = "Fernando";
    const idade = 17;
    const mensagem = `Meu nome é ${nome} e tenho ${idade} anos.`;

    Sem template literals, seria necessário concatenar com +, o que fica menos legível.

    Expressões dentro da string: Não é só variável que funciona. Qualquer expressão JavaScript pode ser usada.

    Exemplo:

    const a = 10;
    const b = 5;
    const resultado = `A soma é ${a + b}`;

    Strings multilinha: Template literals permitem quebrar linhas sem usar \n.

    Exemplo:

    const texto = `Linha 1
    Linha 2
    Linha 3`;

- Estruturas de decisão

    As estruturas de decisão permitem que o código escolha caminhos diferentes com base em condições (verdadeiro ou falso).

    if

        O if executa um bloco de código somente se a condição for verdadeira.

        Exemplo:
        let idade = 18;
        if (idade >= 18) {
            console.log("Maior de idade");
        }

        Se a condição for falsa, o código dentro do if simplesmente não é executado.

    if else

        O if else permite definir o que acontece quando a condição é verdadeira e o que acontece quando é falsa.

        Exemplo:
        let idade = 16;
        if (idade >= 18) {
            console.log("Maior de idade");
        } else {
            console.log("Menor de idade");
        }

        Aqui sempre um dos dois blocos será executado.

    if else if

        Usado quando há várias condições possíveis. O JavaScript testa as condições em ordem, e executa o primeiro bloco verdadeiro.

        Exemplo:
        let nota = 7;
        if (nota >= 9) {
            console.log("Excelente");
        } else if (nota >= 7) {
            console.log("Aprovado");
        } else if (nota >= 5) {
            console.log("Recuperação");
        } else {
            console.log("Reprovado");
        }

    switch

        Usada quando você precisa comparar o valor de uma variável (ou expressão) com vários valores possíveis. Ele costuma ser uma alternativa mais organizada ao uso de vários if / else if.

        O switch avalia uma expressão uma única vez e compara o resultado com cada case. Quando encontra um case correspondente, executa o código daquele bloco.

        Sintaxe básica:

        switch (expressao) {
            case valor1:
                // código se expressao === valor1
                break;
            case valor2:
                // código se expressao === valor2
                break;
            default:
                // código se nenhum case for atendido
        }

        Exemplo:
        let dia = 3;
        switch (dia) {
            case 1:
                console.log("Domingo");
                break;
            case 2:
                console.log("Segunda");
                break;
            case 3:
                console.log("Terça");
                break;
            default:
                console.log("Dia inválido");
        }

        Informações importantes:

        break: o break é essencial na maioria dos casos. Sem ele, o JavaScript continua executando os próximos cases, mesmo que eles não correspondam.

        default: o default funciona como o else final. Ele é executado quando nenhum case corresponde ao valor testado.

        Comparação usada no switch: switch usa comparação estrita (===). Isso significa que tipo e valor precisam ser iguais.

    Operador ternário "?"

        É um operador condicional que funciona como uma forma curta do if/else. Ele é chamado de ternário porque trabalha com três partes.

        Sintaxe:

        condicao ? valorSeVerdadeiro : valorSeFalso

        Se a condição for verdadeira, o operador retorna o primeiro valor. Se for falsa, retorna o segundo.

        Exemplo:

        let idade = 20;
        let resultado = idade >= 18 ? "Maior de idade" : "Menor de idade";

- Conversão de Tipos (explicita)

    Conversão de tipos acontece quando você força explicitamente um valor de um tipo a virar outro tipo. É previsível e controlada.

    Conversão para Number

    Formas comuns:

    Number(valor) - Converte para número ou retorna NaN se não for possível.
    Exemplo:
    Number("10") // 10

    parseInt(valor) - Converte para inteiro e ignora o resto após encontrar algo inválido.
    Exemplo:
    parseInt("10.9") // 10

    parseFloat(valor) - Converte para número decimal.
    Exemplo:
    parseFloat("10.5") // 10.5

    Conversão para String

    Formas comuns:

    String(valor)
    Exemplos:
    String(123) // "123"

    valor.toString()
    Exemplos:
    (123).toString() // "123"

    Conversão para Boolean

    Existe somente uma forma:

    Boolean(valor)
    Exemplos:
    Boolean(0) // false
    Boolean("0") // true

    Valores convertidos para false:

    false
    0
    -0
    0n
    ""
    null
    undefined
    NaN

    Todos os outros valores são true.

- Coerção de Tipos (implicita)

    Coerção ocorre quando o JavaScript converte tipos automaticamente durante operações.

    Coerção com operador +

    O operador + é especial, se algum operando for string faz concatenação, caso contrário é feita soma numérica.

    Exemplos:
    "5" + 2 // "52"
    2 + "5" // "25"
    "5" + true // "5true"
    "5" + null // "5null"
    2 + 2 + "5" // "45"
    "5" + 2 + 2 // "522"

    A ordem importa muito, a mesma é feita da esquerda para a direita.

    Coerção com operadores matemáticos (-, *, /, %)

    Esses operadores sempre tentam converter para Number.

    Exemplos:
    "5" - 2 // 3
    "5" * "2" // 10
    "10" / "2" // 5
    "5" % 2 // 1

- Valores "truthy" e "falsy"

    Qualquer valor pode ser interpretado como verdadeiro (true) ou falso (false) quando usado em contextos lógicos, como if, while, operadores lógicos (&&, ||, !) etc. Esses valores são chamados de "truthy" e "falsy".

    Valores "falsy"

        Falsy são os valores que, quando convertidos para boolean, resultam em false.

        Em JavaScript, existem apenas 7 valores "falsy":

        false
        0
        -0
        0n        (BigInt zero)
        "" ou ''  (string vazia)
        null
        undefined
        NaN

        Exemplos:
        if (false) { }        // não executa
        if (0) { }            // não executa
        if ("") { }           // não executa
        if (null) { }         // não executa
        if (NaN) { }          // não executa

        Qualquer um desses valores dentro de um if será tratado como false.

    Valores "truthy"

        Truthy são todos os outros valores que não estão na lista de falsy. Ou seja, se não é falsy, é truthy.

        Exemplos comuns de valores truthy:

        true
        1
        -1
        "0"
        "false"
        " "        (string com espaço)
        []         (array vazio)
        {}         (objeto vazio)
        function() {}

        Exemplos:
        if (true) { }         // executa
        if (1) { }            // executa
        if ("0") { }          // executa
        if ([]) { }           // executa
        if ({}) { }           // executa

- Operadores de igualdade

    Operadores de igualdade servem para comparar valores. O ponto mais importante é entender a diferença entre comparar "só o valor" e comparar "valor + tipo".

    Operador == (igualdade solta)

        O == compara apenas o valor, não o tipo. Se os tipos forem diferentes, o JavaScript tenta converter (coerção de tipo) antes de comparar.

        Exemplos:
        5 == 5            > true
        5 == "5"          > true
        0 == false        > true
        null == undefined > true

        Isso acontece porque o JavaScript converte os valores para tentar deixá-los do mesmo tipo antes da comparação.

        Esse comportamento pode causar confusão e erros difíceis de perceber.

    Operador === (igualdade estrita)

        O === compara o valor e o tipo ao mesmo tempo. Não existe conversão de tipos.

        Exemplos:
        5 === 5            > true
        5 === "5"          > false
        0 === false        > false
        null === undefined > false

        Esse é o operador recomendado na maioria dos casos, porque o resultado é previsível.

    Operador != (diferença solta)

        O != é o oposto do ==. Ele verifica se os valores são diferentes, permitindo coerção de tipo.

        Exemplos:
        5 != 6        > true
        5 != "5"      > false
        0 != false    > false

        Assim como o ==, ele pode gerar resultados inesperados.

    Operador !== (diferença estrita)

        O !== é o oposto do ===. Ele verifica se o valor ou o tipo são diferentes, sem conversão.

        Exemplos:
        5 !== 6        > true
        5 !== "5"      > true
        0 !== false    > true

- Operadores logicos

    São usados para combinar ou inverter condições. Eles trabalham muito com valores booleanos, mas em JavaScript também retornam valores não booleanos, o que é algo importante de entender.

    Principais: &&, || e !

    Operador && (E lógico)

    O && retorna verdadeiro se todas as condições forem verdadeiras.

    Exemplo básico:
    true && true   > true
    true && false  > false

    Operador || (OU lógico)

    O || retorna verdadeiro se pelo menos uma condição for verdadeira.

    Exemplo básico:
    true || false   > true
    false || false  > false

    Operador ! (NÃO lógico)

    O ! inverte o valor lógico.

    Exemplos:
    !true   > false
    !false  > true

- Declarações e expressões

    São dois conceitos fundamentais que definem como o código é escrito e executado. A diferença principal é que expressões produzem um valor, enquanto declarações executam uma ação.

    Declarações (statements)

        Declarações são instruções completas que dizem ao JavaScript para fazer algo. Elas não retornam um valor que possa ser usado diretamente.

        Exemplos:

        Declaração de variável
        let idade = 18;

        Declarações de controle de fluxo
        if (idade >= 18) {
            console.log("Maior de idade");
        }

        Observação: Você não pode usar uma declaração onde o JavaScript espera um valor.

    Expressões (expressions)

        Expressões são trechos de código que sempre resultam em um valor. Esse valor pode ser usado, atribuído a uma variável, passado como parâmetro, etc.

        Exemplos:

        Expressões literais
        10
        "texto"

        Expressões aritméticas
        5 + 3
        10 * 2

        Expressões de comparação
        idade >= 18
        a === b

        Expressões de atribuição
        x = 10
        y += 2

        Expressões lógicas
        a && b
        a || b

- Strict mode

    É um modo especial de execução que torna a linguagem mais rígida e segura, ajudando a evitar erros comuns e más práticas.

    Ele foi criado para:

    Evitar bugs silenciosos
    Impedir comportamentos perigosos
    Forçar um código mais previsível

    Você ativa o strict mode usando a string abaixo. Ela deve ser usada no topo do arquivo javascript:

    "use strict";

    O que o strict mode muda na prática

    Proíbe variáveis não declaradas
    Impede duplicação de parâmetros
    Proíbe apagar variáveis, funções ou parâmetros
    Impede o uso de palavras reservadas futuras
    Corrige erros silenciosos
    Algumas operações que antes falhavam silenciosamente passam a gerar erro

- Funções

    São blocos de código reutilizáveis que servem para executar uma tarefa ou calcular e retornar um valor. Elas são um dos conceitos mais importantes da linguagem.

    Em vez de repetir o mesmo código várias vezes, você coloca esse código dentro de uma função e a reutiliza sempre que precisar.

    Uma função é um conjunto de instruções que:

        Pode receber dados de entrada (parâmetros)
        Executa um bloco de código
        Pode ou não retornar um valor

    Exemplo simples de ideia:

        Some dois números > isso vira uma função.

    Temos basicamente 3 formatos de declaração de funções:

        Função tradicional (Function Declaration)
        Expressão de função (Function Expression)
        Função seta (Arrow function)

    Diferença nos 3 formatos de declaração de funções:

        Função tradicional (Function Declaration):

            Possui um nome obrigatório.
            Pode ser chamada antes de ser declarada (hoisting).
            Ideal para funções principais do programa.

        Expressão de função (Function Expression):

            Armazenada em variável.
            Passada para outra função.
            Retornada por outra função.
            Não pode ser chamada antes de ser declarada (hoisting).
            Muito comum quando a função será usada como um valor.

        Função seta (Arrow function):

            É uma forma mais curta de escrever funções.
            A grande diferença é o "this".
            A Arrow Function não cria seu próprio this. Ela usa o this do contexto onde foi criada (escopo léxico). Por isso, não é indicada para métodos de objetos.

    Vantagens e desvantagens

        Function Declaration
            Vantagens: Pode ser chamada antes da declaração (hoisting), ótima para funções principais
            Desvantagens: Sintaxe mais longa

        Function Expression
            Vantagens: Trata a função como um valor, ótima para callbacks e atribuições
            Desvantagens: Não possui hoisting

        Arrow Function
            Vantagens: Sintaxe curta, muito usada com map, filter, reduce e callbacks
            Desvantagens: Não possui this próprio e não deve ser usada como método de objeto

    Função tradicional (Function Declaration)

        A função é declarada de forma separada, com nome, e chamada quando necessária.

        Declaração:

            function <nome da função>(<parametro 1>, <parametro 2>, <demais parametros...>) {
                <codigo da função>
                return <valor a ser retornado pela função>
            }

        Chamada:

            <nome da funcao>(<parametro 1>, <parametro 2>, <demais parametros...>);

        Exemplos:

            function logger() {
                console.log("Teste");
            }

            function idade(anoAtual, anoNascimento) {
                let idade = anoAtual - anoNascimento;
                return idade;
            }

            logger();

            idade(2025, 1979);

    Expressão de função (Function Expression)

        A função é declarada sem nome e atribuida a uma variavel, para ser usada é necessario declarar esta variavel.

        Declaração:

            const <nome da variavel> = function(<parametro 1>, <parametro 2>, <demais parametros...>) {
                <codigo da função>
                return <valor a ser retornado pela função>
            }

        Chamada:

            <nome da variavel>(<parametro 1>, <parametro 2>, <demais parametros...>);

        Exemplos:

            const logger = function() {
                console.log("Teste");
            }

            const idade = function(anoAtual, anoNascimento) {
                let idade = anoAtual - anoNascimento;
                return idade;
            }

            logger();

            idade(2025, 1979);

    Função seta (Arrow function)

        A função é declarada sem nome e atribuida a uma variavel, para ser usada é necessario declarar esta variavel. Porem é uma forma mais curta e moderna de escrever funções pois não leva a palavra function.

        Declaração:

            const <nome da variavel> = (<parametro 1>, <parametro 2>, <demais parametros...>) => {
                <codigo da função>
                return <valor a ser retornado pela função>
            }

        Chamada:

            <nome da variavel>(<parametro 1>, <parametro 2>, <demais parametros...>);

        Exemplos:

            const logger = () => {
                console.log("Teste");
            }

            const idade = (anoAtual, anoNascimento) => {
                let idade = anoAtual - anoNascimento;
                return idade;
            }

            logger();

            idade(2025, 1979);

- Arrays

    São estruturas de dados usadas para armazenar vários valores em uma única variável, organizados por índice numérico. Eles são fundamentais para trabalhar com listas de dados.

    Características importantes

        Cada elemento tem um índice (posição)
        O índice começa em 0
        Pode armazenar qualquer tipo de dado
        Pode misturar tipos diferentes (número, string, objeto, função, etc.)
        O tamanho pode mudar dinamicamente

    Declaração

        Forma literal (mais comum)

            // Vazio
            let <nome do array> = [];

            // Com itens
            let <nome do array> = [<item>, <item>, ...];

            Exemplos:

            let frutas = [];
            let frutas = ["maçã", "banana", "laranja"];

            É a forma recomendada por ser mais simples e clara.

        Usando o construtor Array

            // Vazio
            let <nome do array> = new Array();

            // Com itens
            let <nome do array> = new Array(<item>, <item>, ...);

            Exemplos:

            let frutas = new Array();
            let frutas = new Array("maçã", "banana", "laranja");

            Funciona, mas é menos usada.

    Arrays podem misturar tipos

        let dados = [1, "texto", true, { nome: "Ana" }, function() {}];

        Isso é permitido em JavaScript.

     Tamanho do array (length)

        A propriedade length indica o número de elementos.

        cores.length; // 3

        Importante, length não é método, é propriedade.

    Acessando elementos do array

        let cores = ["azul", "verde", "vermelho", "amarelo"];

    Mostrar todos

        Não colocar nenhum indice dentro do colchetes:

        cores[]; // "azul", "verde", "vermelho", "amarelo"

    Primeiro elemento do array

        É sempre o item na posição zero "0":

        cores[0]; // "azul"

    Elementos em posição especifica

        Use o índice desejado entre colchetes:

        cores[1]; // "verde"
        cores[2]; // "vermelho"

    Ultimo elemento do array

        Usar a propriedade length e subtrair 1.

        cores.length - 1

        Exemplo:

        cores[cores.length - 1]; // "amarelo"

    Adicionar elementos (operações comuns)

        Ao inserir um item seu metodo retorno o novo tamanho do array (caso necessario utilziarmos).

        let numeros = [1, 2];

        Adicionar no início (unshift):

        numeros.unshift(0);
        // [0, 1, 2]

        Adicionar em local especifico (splice):

        array.splice(<indice>, <qtde de itens a remover>, <item a ser inserido>);

        Exemplo:

        let frutas = ["maçã", "banana", "laranja"];
        frutas.splice(1, 0, "uva");

        Resultado:
        // ["maçã", "uva", "banana", "laranja"]

        Adicionar no final (push):

        numeros.push(3);
        // [0, 1, 2, 3]

    Remover elementos

        Ao remover um elemento seu metodo retorna o item removido (caso necessario utilizarmos).

        Remover do início (shift):

        numeros.shift();
        // remove o primeiro

        Remover em local especifico (splice):

        array.splice(<indice a ser removido>, 1);

        Exemplo:

        let frutas = ["maçã", "banana", "laranja"];
        frutas.splice(1, 1);

        Resultado:
        // ["maçã", "laranja"]

        Remover do final (pop):

        numeros.pop();
        // remove o último     

    Buscar elementos

        Verificar se existe (includes):

        numeros.includes(2); // true

        Encontrar índice (indexOf):

        numeros.indexOf(2); // retorna o índice ou -1

- Objetos

    São estruturas de dados usadas para representar entidades do mundo real, agrupando propriedades (dados) e comportamentos (funções) em um único lugar.

    Um objeto é uma coleção de pares "chave : valor".

    A chave (propriedade) é uma string
    O valor pode ser qualquer tipo de dado: número, string, boolean, array, função, outro objeto etc.

    Exemplo:

    let pessoa = {
        nome: "Ana",
        idade: 25,
        ativo: true
    };

    Diferença entre objetos e arrays

        Array:

        Usado para listas ordenadas
        Acesso por índice numérico
        Ordem importa

        Exemplo:

        let numeros = [10, 20, 30];

        Objeto:

        Usado para representar coisas com atributos
        Acesso por nome da propriedade
        Ordem não é o foco

        Exemplo:

        let pessoa = { 
            nome: "Ana", 
            idade: 25 
        };

    Declarando objetos

        Forma literal (mais comum)

        let carro = {
            marca: "Ford",
            modelo: "Fiesta",
            ano: 2018
        };

        Objeto vazio e adicionar propriedades depois

        let usuario = {};
        usuario.nome = "Carlos";
        usuario.idade = 30;

        Usando new Object (pouco usado) e adicionar propriedades depois

        let produto = new Object();
        produto.nome = "Teclado";

        A forma literal {} é a recomendada.

    Acessando propriedades

        Notação com ponto (.)

        Usada quando o nome da propriedade é conhecido e válido.

        pessoa.nome;
        pessoa.idade;

        Exemplo:
        console.log(pessoa.nome);

        Notação com colchetes []

        Usada quando:

        O nome da propriedade está em uma variável
        A propriedade tem espaços ou caracteres especiais

        Exemplo:

        let prop = "idade";
        pessoa[prop];

        Exemplo com nome inválido:

        let obj = {
        "nome completo": "Ana Silva"
        };
        obj["nome completo"];

    Adicionando propriedades

        Com ponto:

        pessoa.altura = 1.70;

        Com colchetes:

        pessoa["peso"] = 65;

        Usando variável:

        let chave = "cidade";
        pessoa[chave] = "São Paulo";

    Função como propriedade (métodos)

        Quando uma função está dentro de um objeto, ela é chamada de método.

        Exemplo:

        let pessoa = {
            nome: "Ana",
            idade: 25,
            falar: function() {
                console.log("Olá, meu nome é " + this.nome);
            }
        };

        Chamando o método:

        pessoa.falar();

        Forma curta (mais moderna):

        let pessoa = {
            nome: "Ana",
            falar() {
                console.log("Olá, meu nome é " + this.nome);
            }
        };

    this

        this é uma palavra-chave que se refere ao objeto que está chamando a função.

        No exemplo:

        pessoa.falar();

        Dentro da função:
        this === pessoa

        Por isso:
        this.nome acessa pessoa.nome

        Exemplo:

        let carro = {
            marca: "Toyota",
            mostrarMarca() {
                console.log(this.marca);
            }
        };

        carro.mostrarMarca();

        Cuidado com arrow function e this, arrow functions não têm this próprio.

- Estruturas de repetição

    Servem para executar o mesmo bloco de código várias vezes, enquanto uma condição for atendida ou enquanto houver itens a percorrer.

    for

        O for é usado quando você sabe ou consegue prever quantas vezes o loop vai rodar.

        Estrutura:

        for (inicialização; condição; incremento) {
            // código executado a cada repetição
        }

        Exemplo:

        for (let i = 0; i < 5; i++) {
            console.log(i);
        }

        O que cada parte faz:

        inicialização > cria a variável de controle (let i = 0)
        condição > enquanto for true, o loop continua (i < 5)
        incremento > executado ao final de cada volta (i++)

        Uso comum:

        Percorrer arrays
        Contadores

    while

        O while é usado quando não se sabe exatamente quantas vezes o loop vai rodar, apenas a condição.

        Estrutura:

        while (condição) {
            // código executado a cada repetição
        }

        Exemplo:

        let i = 0;

        while (i < 5) {
            console.log(i);
            i++;
        }

        Se a condição começar falsa, o código nunca executa.

        Uso comum:

        Esperar um evento
        Ler dados até uma condição ser atendida

    do while

        O do while é parecido com o while, mas com uma diferença importante:

        Ele sempre executa pelo menos uma vez.

        Estrutura:

        do {
            // código executado a cada repetição
        } while (condição);

        Exemplo:

        let i = 10;

        do {
            console.log(i);
            i++;
        } while (i < 5);

        Mesmo com a condição falsa, o código roda uma vez.

    Diferença entre for, while e do while

        for:

        Ideal quando sabe o número de repetições
        Tudo fica em uma linha (controle claro)

        while:

        Testa a condição antes
        Pode não executar nenhuma vez

        do while:

        Testa a condição depois
        Executa pelo menos uma vez

    break

        O break interrompe completamente o loop, mesmo que a condição ainda seja verdadeira.

        Exemplo:

        for (let i = 0; i < 10; i++) {
            if (i === 5) {
                break;
            }
            console.log(i);
        }

        Resultado:
        0 1 2 3 4

        Uso comum:

        Parar quando encontrar um valor específico
        Evitar processamento desnecessário

    continue

        O continue pula a iteração atual e vai direto para a próxima.

        Exemplo:

        for (let i = 0; i < 5; i++) {
            if (i === 2) {
                continue;
            }
            console.log(i);
        }

        Resultado:
        0 1 3 4

        Uso comum:

        Ignorar certos valores
        Filtrar dentro do loop

    Comparação rápida entre break e continue

        break > sai do loop
        continue > pula a volta atual

- O que é HTML?

    HTML (HyperText Markup Language) é a linguagem usada para criar a estrutura de uma página da web, como títulos, textos, imagens, links e tabelas.

- O que é CSS?

    CSS (Cascading Style Sheets) é a linguagem usada para definir a aparência da página, como cores, fontes, tamanhos, margens e posicionamento dos elementos.

- O que é o arquivo index.html?

    É o arquivo principal de um site. Quando você acessa um endereço na web, normalmente o navegador procura primeiro pelo arquivo index.html.

- Como criar um arquivo básico HTML no VS Code?

    Abra o VS Code.
    Crie uma nova pasta para o projeto.
    Crie um arquivo chamado index.html.
    Digite ! e pressione Enter (ou Tab). O VS Code criará automaticamente a estrutura básica do HTML.

- Explicação básica de um arquivo HTML gerado pelo VS Code

    <!doctype html>
    <html lang="en">
        <head>
            <meta charset="UTF-8" />
            <meta name="viewport" content="width=device-width, initial-scale=1.0" />
            <title>Document</title>
        </head>
        <body></body>
    </html>

    <!doctype html> - Informa ao navegador que o documento usa HTML5.
    <html> - Contém todo o conteúdo da página.
    lang="en" - Define o idioma da página (neste caso, inglês).
    <head> - Contém informações da página que não aparecem no conteúdo, como título e configurações.
    <meta charset="UTF-8"> - Permite usar caracteres especiais, como ç e á.
    <meta name="viewport"...> - Faz a página se adaptar corretamente a celulares e tablets.
    <title> - Define o título exibido na aba do navegador.
    <body> - Contém todo o conteúdo visível da página, como textos, imagens e botões.

- O que é versao em documento HTML?

    Em HTML, a versão do documento indica qual padrão de HTML o navegador deve usar para interpretar a página.

    Hoje, praticamente todos os sites usam HTML5.

    Isso é informado logo na primeira linha do arquivo:

    <!doctype html>

    Essa linha diz ao navegador:

    "Este documento foi escrito usando o padrão HTML5."

    Por que isso é importante?

    Se essa declaração não existir ou estiver incorreta, o navegador pode entrar em um modo de compatibilidade ("Quirks Mode"), interpretando a página como se fosse uma versão muito antiga do HTML, o que pode causar problemas de layout e funcionamento.

- O que são elementos HTML?

    Elementos HTML são as partes que formam uma página, como títulos, parágrafos, imagens e links. Geralmente são compostos por uma tag de abertura, conteúdo e uma tag de fechamento.

    Exemplo:

    <p>Olá, mundo!</p>

- O que são tags HTML?

    Tags são os comandos usados para criar elementos HTML. Elas ficam entre os símbolos < e >.

    Exemplos:

    <h1>
    <p>
    <img>
    <a>

- O que são atributos HTML?

    Atributos fornecem informações extras para uma tag. Eles são escritos dentro da tag de abertura.

    Exemplo:

    <img src="foto.jpg" alt="Minha foto">
    src - Informa onde está a imagem.
    alt - Define um texto alternativo para a imagem.

- O que é aninhamento de elementos?

    Aninhamento é quando um elemento HTML é colocado dentro de outro elemento.

    Exemplo:

    <body>
        <h1>Meu Site</h1>
        <p>Bem-vindo!</p>
    </body>

    Nesse exemplo, as tags <h1> e <p> estão aninhadas dentro da tag <body>.

- O que é elemento pai e elemento filho?

    Quando um elemento está dentro de outro:

    Elemento pai - É o elemento que contém outro elemento.
    Elemento filho - É o elemento que está dentro do elemento pai.

    Exemplo:

    <body>
        <p>Olá, mundo!</p>
    </body>

    <body> - elemento pai.
    <p> - elemento filho.

- O que são "class" e "id"?

    São atributos HTML usados para identificar elementos.

    "class"

    Serve para identificar um ou vários elementos com o mesmo nome.

    Exemplo:

    <p class="texto">Primeiro parágrafo</p>
    <p class="texto">Segundo parágrafo</p>

    Ambos pertencem à classe texto.

    "id"

    Serve para identificar um único elemento da página.

    Exemplo:

    <h1 id="titulo">Meu Site</h1>

    O id="titulo" deve ser único na página.

- O que é DOM?

    DOM (Document Object Model) é a representação da página HTML em forma de árvore, criada pelo navegador.

    Ela permite que o JavaScript encontre, altere, adicione ou remova elementos da página.

    Exemplo:

    <body>
        <h1>Título</h1>
        <p>Texto</p>
    </body>

    O navegador transforma esse HTML em uma estrutura organizada (árvore), chamada DOM.

- O que é semântica em HTML?

    Semântica é usar a tag correta para cada tipo de conteúdo, tornando o código mais organizado, acessível e fácil de entender.

    Exemplos de tags semânticas:

    <header> - cabeçalho
    <nav> - menu de navegação
    <main> - conteúdo principal
    <section> - seção da página
    <article> - artigo ou conteúdo independente
    <footer> - rodapé

    Em vez de escrever tudo com <div>, usamos tags que descrevem o significado do conteúdo.

    Exemplo:

    <header>
        <h1>Meu Site</h1>
    </header>

    <main>
        <p>Bem-vindo ao site.</p>
    </main>

    <footer>
        <p>Todos os direitos reservados.</p>
    </footer>

- O que é CSS

    CSS (Cascading Style Sheets) é uma linguagem usada para definir como os elementos HTML serão exibidos.

    Todo CSS possui três partes:

    seletor {
        propriedade: valor;
    }

        color: red;
    }

    Onde:

    p - seletor (o elemento que sera configurado)
    color - propriedade (a propriedade do elemento que sera alterada)
    red - valor ( o valor que sera atribuido a essa propriedade)

    <link rel="stylesheet" href="style.css">

- CSS Reset

- CSS Box Model

    O CSS Box Model (Modelo de Caixa) é um dos conceitos mais importantes do CSS. Ele define como o navegador calcula o tamanho e o espaço ocupado por cada elemento HTML.

    A ideia principal é que todo elemento HTML é tratado como uma caixa (box).

    Estrutura do Box Model

        Um elemento é composto por quatro partes:

        +-------------------------------------------+
        |                  Margin                   |
        |  +-------------------------------------+  |
        |  |               Border                |  |
        |  |  +-------------------------------+  |  |
        |  |  |            Padding            |  |  |
        |  |  |  +-------------------------+  |  |  |
        |  |  |  |         Content         |  |  |  |
        |  |  |  +-------------------------+  |  |  |
        |  |  +-------------------------------+  |  |
        |  +-------------------------------------+  |
        +-------------------------------------------+

        Da parte de dentro para fora:

        Content (Conteúdo): É onde ficam os dados do elemento
        Padding (Espaçamento interno): O padding é o espaço entre o conteúdo e a borda.
        Border (Borda): É a borda do elemento.
        Margin (Espaçamento externo): A margem fica do lado de fora.

    Como o navegador calcula o tamanho?

        Suponha:

        width: 300px;
        padding: 20px;
        border: 5px;

        Sem alterar box-sizing, o tamanho total será: Conteúdo = 300px

        Padding esquerdo = 20px
        Padding direito = 20px
        Border esquerda = 5px
        Border direita = 5px

        Total: 300 + 20 + 20 + 5 + 5 = 350px

        Ou seja: width total = 350px

    O problema do Box Model padrão

        Por padrão, o navegador usa:

        box-sizing: content-box;

        Isso significa que a propriedade width controla apenas a área do conteúdo.

        Exemplo:

        width: 300px;
        padding: 20px;
        border: 5px solid;

        Resultado: Tamanho total = 350px

        Isso pode dificultar o controle do layout.

    A solução

        box-sizing: border-box

        O navegador ajusta o conteúdo para que o tamanho total continue sendo 300px.

        300px (total)

        ┌─────────────────────────────┐
        │ Border                      │
        │ Padding                     │
        │ Conteúdo (reduzido)         │
        └─────────────────────────────┘

        Isso torna os layouts muito mais previsíveis, evita surpresas com o cálculo do tamanho dos elementos e facilita bastante a construção de layouts com CSS.

- Medidas em CSS

    São as unidades usadas para definir tamanhos, espaçamentos, posições e dimensões dos elementos.

    Existem dois grandes grupos:

    Medidas absolutas
    Medidas relativas

    Medidas Absolutas

        São unidades de tamanho fixo. Elas não mudam de acordo com a tela ou o tamanho da fonte.

        "px" (Pixels) é a unidade mais utilizada.

        Quando usar?

        Bordas
        Ícones
        Pequenos espaçamentos
        Elementos que precisam de tamanho fixo

        Na prática, para páginas web, quase sempre usa-se "px".

    Medidas Relativas

        São calculadas com base em outro valor, como o tamanho da fonte, do elemento pai ou da janela do navegador.

        São as mais indicadas para criar layouts responsivos.

        "%" a porcentagem depende do elemento pai.

        "em" é baseado no tamanho da fonte do elemento pai (atenção ao efeito cascata pois ele multiplica sobre o valor herdado).

        "rem" significa "Root EM", ele sempre usa o tamanho da fonte do elemento <html>.

        "auto" permite que o navegador calcule o valor automaticamente (muito usado para centralizar elementos)

        Por que usar "rem"?

            Ele facilita a acessibilidade. Se o usuário aumentar o tamanho padrão da fonte no navegador, todos os elementos definidos em "rem" aumentam proporcionalmente.

        Comparação das principais unidades

            | Unidade | Base de cálculo           | Uso recomendado                                        |
            | ------- | ------------------------- | ------------------------------------------------------ |
            | "px"    | Valor fixo                | Bordas, ícones, detalhes                               |
            | "%"     | Elemento pai              | Largura e altura relativas                             |
            | "em"    | Fonte do elemento pai     | Espaçamentos e componentes, com cuidado ao aninhamento |
            | "rem"   | Fonte do <html>           | Tamanho de texto e espaçamentos (muito recomendado)    |

        Recomendações para iniciantes

            Use "px" para bordas, sombras e pequenos detalhes visuais.
            Prefira "rem" para tamanhos de fonte, margens e padding, pois melhora a consistência e a acessibilidade.
            Use "%" para elementos que devem acompanhar o tamanho do elemento pai.

- Javascript como selecionar elementos no HTML

    Uma das tarefas mais comuns em JavaScript é selecionar elementos da página HTML para poder ler informações, alterar conteúdo, modificar estilos ou responder a eventos.

    O JavaScript faz isso através do DOM (Document Object Model).

    Métodos mais utilizados

        Hoje, os métodos mais usados são:

        | Método                              | Retorna                     
        | ----------------------------------- | ----------------------------
        | document.querySelector()            | Primeiro elemento encontrado
        | document.querySelectorAll()         | Lista de elementos          
        | document.getElementById()           | Elemento pelo id            
        | document.getElementsByClassName()   | Coleção de elementos        
        | document.getElementsByTagName()     | Coleção de elementos        
        | document.getElementsByName()        | Coleção de elementos        

        Os três primeiros são os que você usará na maior parte do tempo.

    Selecionar pelo ID (getElementById)

        Como o id deve ser único na página esse método retorna apenas um elemento.

        Exemplo:

        const titulo = document.getElementById("titulo");

    Selecionar pela Classe (getElementsByClassName)

        Como uma classe pode ser usada em diversos elementos esse método retorna uma HTMLCollection.

        Exemplo:

        const textos = document.getElementsByClassName("texto");

    Selecionar pela Tag (getElementsByTagName)

        Como podem existir diversos elementos esse método retorna uma HTMLCollection.

        Exemplo:

        const paragrafos = document.getElementsByTagName("p");

    Seletor diversificado (querySelector)

        Esse método retorna apenas um elemento, o primeiro encontrado.

        É o método mais utilizado atualmente, ele aceita qualquer seletor.

        # para id
        . para classe
        propria tag para tag

        Exemplo:

        const titulo = document.querySelector("#titulo");
        const texto = document.querySelector(".texto");
        const h1 = document.querySelector("h1");

    Seletor diversificado (querySelectorAll)

        Esse método retorna uma NodeList pois pode encontrar diversos elementos.

        Ele aceita qualquer seletor.

        # para id
        . para classe
        propria tag para tag

        Exemplo:

        const titulo = document.querySelectorAll("#titulo");
        const texto = document.querySelectorAll(".texto");
        const h1 = document.querySelectorAll("h1");

    Qual método usar?

        Na maioria dos projetos modernos:

        Use "document.querySelector()" quando precisar de um único elemento.
        Use "document.querySelectorAll()" quando precisar de vários elementos.

- O que é uma NodeList e uma HTMLCollection

    Quando você seleciona vários elementos do HTML, o JavaScript não retorna um array comum. Em vez disso, ele retorna um objeto especial, que pode ser uma NodeList ou uma HTMLCollection, dependendo do método utilizado.

    Embora pareçam arrays, eles têm diferenças importantes.

    O que é uma NodeList?

        Uma NodeList é uma coleção (lista) de nós do DOM.

        Normalmente, você a obtém com:

        document.querySelectorAll();

        Exemplo:

        <p>Primeiro</p>
        <p>Segundo</p>
        <p>Terceiro</p>
        const paragrafos = document.querySelectorAll("p");
        console.log(paragrafos);

        Resultado:

        NodeList(3)

        Ela contém os três elementos <p>.

        Acessando elementos:

        console.log(paragrafos[0]);
        console.log(paragrafos[1]);
        console.log(paragrafos[2]);

        Resultado:

        <p>Primeiro</p>
        <p>Segundo</p>
        <p>Terceiro</p>

        Percorrendo uma NodeList:

        Uma grande vantagem é que ela possui o método forEach().

        paragrafos.forEach(function (p) {
            console.log(p);
        });

    O que é uma HTMLCollection?

        Uma HTMLCollection é uma coleção de elementos HTML.

        Ela é retornada por métodos como:

        document.getElementsByClassName();
        document.getElementsByTagName();

        Exemplo:

        const paragrafos = document.getElementsByTagName("p");

        Resultado:

        HTMLCollection(3)

        Acessando elementos:

        console.log(paragrafos[0]);
        console.log(paragrafos[1]);
        console.log(paragrafos[2]);

        É exatamente igual à NodeList.

        Percorrendo uma HTMLCollection:

        Ela não possui forEach().

        O jeito mais comum é usar for...of:

        for (const p of paragrafos) {
            console.log(p);
        }

        Ou um for tradicional:

        for (let i = 0; i < paragrafos.length; i++) {
            console.log(paragrafos[i]);
        }

    Diferença mais importante: coleção "viva" (live) e "estática" (static)

    Essa é a principal diferença entre elas.

    HTMLCollection é "live"

        Ela acompanha automaticamente as alterações no DOM.

        Exemplo:

        <body>
            <p>Um</p>
            <p>Dois</p>
        </body>

        const paragrafos = document.getElementsByTagName("p");
        console.log(paragrafos.length); // 2
        const novo = document.createElement("p");
        novo.textContent = "Três";
        document.body.appendChild(novo);
        console.log(paragrafos.length); // 3

        A coleção foi atualizada automaticamente.

    NodeList é "estática"

        Ela representa uma "fotografia" do momento em que foi criada.

        const paragrafos = document.querySelectorAll("p");
        console.log(paragrafos.length); // 2
        const novo = document.createElement("p");
        novo.textContent = "Três";
        document.body.appendChild(novo);
        console.log(paragrafos.length); // continua 2

        Para obter a lista atualizada, é necessário fazer a seleção novamente:

        const paragrafosAtualizados = document.querySelectorAll("p");

    Convertendo para um Array

        Se você quiser usar métodos como map(), filter() ou reduce(), pode converter qualquer uma delas em um array.

        const lista = document.querySelectorAll("p");
        const array = Array.from(lista);
        console.log(array);

        Ou:

        const lista = document.getElementsByClassName("texto");
        const array = Array.from(lista);

    Qual usar?

        Hoje, em projetos modernos, a maioria dos desenvolvedores prefere:

        document.querySelector();
        document.querySelectorAll();

        Motivos:

        usam os mesmos seletores do CSS;
        são mais flexíveis;
        NodeList oferece o método forEach();
        a coleção estática evita comportamentos inesperados quando o DOM muda;

- O que são Web APIs

    As Web APIs são funcionalidades disponibilizadas pelo navegador para que o JavaScript possa interagir com a página, o computador do usuário e serviços da web.

    Uma dúvida muito comum é pensar que tudo faz parte do JavaScript. Na verdade, não faz.

    O JavaScript é apenas a linguagem. Quem fornece recursos como manipular o HTML, fazer requisições HTTP ou usar o GPS é o navegador, por meio das Web APIs.

    Quem faz o quê?

        Podemos imaginar a arquitetura assim:

        Seu código JavaScript
                │
                ▼
        Engine JavaScript (V8, SpiderMonkey...)
                │
                ▼
            Web APIs
                │
                ▼
            Navegador


        JavaScript executa seu código.
        Web APIs oferecem funcionalidades extras.
        Navegador implementa essas APIs.

        Exemplo: 

        console.log("Olá");

        console.log() não faz parte da linguagem JavaScript. Quem fornece o objeto console é o navegador (ou o ambiente de execução, como o Node.js).

        document.querySelector("h1");

        Também não faz parte do JavaScript. O objeto document pertence à DOM API, que é uma Web API.

    Principais Web APIs

        | API               | Para que serve?                                                          |
        | ------------------| ------------------------------------------------------------------------ |
        | DOM API           | Manipular HTML e CSS                                                     |
        | Events API        | Responder a cliques, teclado, mouse etc.                                 |
        | Fetch API         | Fazer requisições HTTP                                                   |
        | Timer API         | Executar código após um tempo ou em intervalos                           |
        | Local Storage API | Armazenar dados no navegador                                             |
        | Geolocation API   | Obter a localização do usuário                                           |
        | Clipboard API     | Copiar e ler texto da área de transferência                              |
        | Canvas API        | Desenhar gráficos e animações                                            |
        | Audio/Video API   | Controlar mídia                                                          |
        | BOM               | Acessar informações do navegador (`window`, `location`, `history`, etc.) |

    Testar programas durante o desenvolvimento

    alert(<mensagem>);

- Funções matematicas com Math

    Math.random()

        É um método do objeto Math que gera um número aleatório.

        Sempre retorna um número entre 0 (inclusive) até 1 (exclusivo). Nunca retorna exatamente 1.

        Ou seja:

        0 <= número < 1

        Exemplos:

        0.12345
        0.98765
        0.00012

        Sintaxe:

        Math.random()

        Exemplo:

        const numero = Math.random();

    Math.trunc()

        Remove a parte decimal de um número. Não arredonda. Apenas corta.

        Sintaxe:

        Math.trunc(<valor>);

        Exemplo:

        Math.trunc(4.9)

        Resultado:

        4

- Gerar numeros inteiros aleatorios entre range de valores

    Utilizar a formula abaixo:

    Math.trunc(Math.random() * (max - min + 1)) + min;

    Exemplo:

    Gerando de 1 a 10

    const numero = Math.trunc(Math.random() * (10 - 1 + 1)) + 1;

    Gerando de 20 a 50

    const numero = Math.trunc(Math.random() * (50 - 20 + 1)) + 20;

- Adicionando eventos ao HTML

    É utilizado o método "addEventListener()" para isso, ele adiciona um evento a um elemento.

    É uma das funções mais importantes do JavaScript.

    Sintaxe:

    <elemento>.addEventListener(<evento>, <função>);

    Exemplo:

    const botao = document.querySelector(".btn");

    botao.addEventListener("click", function () {
        console.log("Clicou!");
    });

    Eventos comuns:

    Evento	    O que faz

    click	    Clique
    input	    Digitação
    change	    Mudança de valor
    submit	    Envio do formulário
    keydown	    Tecla pressionada
    keyup	    Tecla solta
    mouseover	Mouse entrou

    Voce pode inserir a funcao direto no evento ou criar uma função a parte e inserir sua declaração no evento, por exemplo:

    function clicou() {
        console.log("Clicou!");
    }

    const botao = document.querySelector(".btn");

    botao.addEventListener("click", clicou);

    Um ponto iportante é nao usar parenteses () pois a funcao nao deve ser chamda e sim passada ao evento.

- Parametro "e" em addEventListener

    Por exemplo o codigo abaixo:

    document.addEventListener("keydown", function (e) {
        console.log(e.key);
    });

    A função do addEventListener pode receber um parametro "e" e o que seria este parametro?

    O parâmetro "e" é um objeto criado automaticamente pelo navegador no momento em que o evento acontece.

    Ele é um objeto que contém várias informações sobre o evento que acabou de acontecer.

    O nome "e" é apenas um nome de variável mas é o padrao normalmente utilizado neste caso.

    Seu retorno neste caso é:

    ...
    key: "Enter"
    keyCode: 13
    charCode: 0
    code: "Enter"
    ctrlKey: false
    altKey: false
    metaKey: false
    ...

    A propriedade "key" informa a tecla pressionada.

    Dependendo do tipo de evento (clique de mouse por exemplo) estas informações podem ser diferentes.

- Manipulando o DOM com propriedades dos elementos

    .textContent

        Lê ou altera o texto de um elemento HTML.

        Exemplo:

        <p class="mensagem">Olá</p>

        Ler o texto:
        const msg = document.querySelector(".mensagem");

        Alterar o texto:
        msg.textContent = "Você ganhou!";

    .value

        Obtém ou altera o valor de campos de formulário.

        É usado em:

        input
        textarea
        select

        Exemplo:

        <input class="numero">

        Ler o valor:
        const campo = document.querySelector(".numero");

        Alterar o valor:

        campo.value = "";

    .style

        Permite alterar estilos CSS diretamente pelo JavaScript.

        Exemplo:

        <p class="texto">Olá</p>

        const texto = document.querySelector(".texto");
        texto.style.color = "red";
        texto.style.backgroundColor = "yellow";

        Observe que propriedades CSS com hífen (background-color) viram camelCase (backgroundColor) no JavaScript.

    .classList

        Permite manipular classes CSS. É muito melhor do que alterar .style várias vezes.

        Exemplos:

        Adicionar classe
        elemento.classList.add("hidden");

        Remover classe
        elemento.classList.remove("hidden");

        Alternar
        elemento.classList.toggle("hidden");

        Funcionamento:

        Se existir: remove
        Se não existir: adiciona
        Verificar (retorna true ou false): elemento.classList.contains("hidden")

    .disabled

        Habilita ou desabilita elementos.

        Muito usado em botões.

        Exemplo:

        botao.disabled = true;
        botao.disabled = false;

        Também funciona em:

        input
        select
        textarea

    .checked

        Indica se um checkbox ou radio está marcado.

        Retorna true ou false.

        Exemplo:

        <input type="checkbox" class="aceite">

        const aceite = document.querySelector(".aceite");
        console.log(aceite.checked);

        Se estiver marcado true senao retorna false

        Também pode marcar pelo JavaScript:

        aceite.checked = true;

        Ou desmarcar:

        aceite.checked = false;
